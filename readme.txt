A lightweight, accessibility-ready block theme for nonprofits and congregations.

== Description ==

Kindly is a from-scratch Full Site Editing (FSE) block theme made for nonprofits, charities, and congregations. It ships lightweight (no page builder, core blocks only), accessibility-ready to WCAG 2.2 AA, and with nothing locked behind a Pro upgrade.

Highlights:

* Block patterns for the sections these sites actually need — welcome hero, service times, mission, activities, a "serve / get involved" call to action, humanitarian outreach, announcements, location, and contact. A donation pattern is included but optional and is not part of the default home page.
* Three style variations (Faith, Charity, Community) — switch the whole look from the Site Editor. Every variation passes WCAG AA color contrast.
* Fluid typography, a semantic color palette, and a consistent spacing scale, all defined in theme.json.
* Fonts bundled locally (no external requests).

Real donation processing, event management, and contact forms are intentionally left to plugins (for example a donations plugin, an events plugin, or a forms plugin); Kindly provides the layouts.

== Installation ==

1. In your WordPress dashboard, go to Appearance > Themes > Add New > Upload Theme.
2. Upload the theme zip and click Activate.
3. Go to Appearance > Editor to customize templates, choose a style variation, and assemble pages from the included patterns.

== Frequently Asked Questions ==

= Does Kindly handle donations or events? =

No — by design. Kindly provides accessible layouts (a donation call to action, an activities grid, a contact section). Pair it with your preferred donations, events, or forms plugin to add the functionality.

= How do I change the colors? =

Open the Site Editor (Appearance > Editor), go to Styles, and pick one of the three variations, or customize the palette directly.
